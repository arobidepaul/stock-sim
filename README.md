# Stock Sim

A browser game for practicing stock trading without real money. Start with $10,000 in fake cash, buy and sell shares of 3 fake companies over 20 turns while their prices randomly rise and fall, and try to end with the highest portfolio value.

## Run it

```
node server.js
```

Then open http://localhost:8001 in a browser. No install step, no API keys — prices are simulated locally.

## Run the tests

```
node --test
```
